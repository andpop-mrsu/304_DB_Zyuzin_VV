# Лабораторная работа 1: Подготовка окружения. Настройка Git и SQLite, получение исходных данных

### Cтруктура файлов данных:
- `ratings.csv` - txt-файл содержащий исходные данные
- `sqlite.txt` - txt-файл содержащий номер версии SQLite и режимы вывода данных, доступные в утилите sqlite3.
- `ratings_count.txt` - txt файл с min/max идентификатором пользователя из файла ratings.csv и количеством строк с этим идентификатором.
- `users.txt` - txt-файл с столбцами ID|ФИО|Почта|Пол|Дата|Профессия
- `tags.csv` - csv-файл с столбцами userId|movieId|tag|timestamp
- `occupation.txt` - txt-файл содержащий некоторые профессии
- `movies.txt` - txt-файл с столбцами movieId|title|genres
- `genres.txt` - txt-файл содержащий некоторые жанры фильмов
