# Лабораторная работа №2. Подготовка скриптов для создания таблиц и добавления данных

## Описание
Утилита на Python читает текстовые файлы из каталога `dataset/` и генерирует SQL-скрипт для создания таблиц и быстрой загрузки данных. Shell-скрипт автоматизирует процесс и инициализирует базу данных.

## Структура проекта
```text
Task02/
├── dataset/             # исходные файлы данных (.csv, .txt)
├── make_db_init.py      # утилита генерации SQL-скрипта
├── db_init.bat          # bash-скрипт запуска
└── README.md
```

## Требования к окружению
Для корректной работы `db_init.bat` необходимы:
* **Python 3**
* **SQLite3** (консольная утилита)
* **Bash** (Git Bash для Windows / стандартный терминал для Linux/macOS)

## Запуск
В терминале перейдите в папку `Task02` и выполните команду:
```bash
./db_init.bat
```

**Результат:** В каталоге появятся сгенерированный скрипт `db_init.sql` и готовая заполненная база данных `movies_rating.db`.
